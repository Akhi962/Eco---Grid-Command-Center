# ⚡ EcoChain: Clean-Grid Micro Routing Planner

A high-velocity, real-time command visualizer engineered to optimize and secure downstream power routing sequences across sustainable micro-grids. Developed for **HackNova**.

## 🚀 The Core Philosophy: Class-Free Innovation
Most traditional software approaches build sequential networks using rigid, memory-heavy object-oriented class loops (`class Node` and `self.next`). **AethelGrid completely bypasses this object boilerplate.** 

Instead, the platform tracks systemic grid states, battery levels, and localized infrastructure relays entirely within high-speed, mutable **Python Dictionary Topologies**. Because dictionaries compile down to highly optimized C-code arrays under the hood, our data routing evaluations cut down processing latency drastically, translating states directly into an interactive user viewport.

## 🛠️ Key Features
- **3D Celestial Gateway:** An immersive, lightweight vector-drawn landing module inspired by classical Roman mythology to secure grid initialization.
- **Executive KPI Metrics:** Large, reactive status blocks monitoring total system generation capacity, load requirements, and target grid utilization factors.
- **Visual Network Flow Map:** An interface map that dynamically shifts hex color styles (Green, Orange, Red) live as downstream grid connections mutate or fail.
- **Live System Stress Testing:** Responsive manual load adjusters allowing operators to simulate overload thresholds, forcing automated battery backup triggers or circuit breaks.

## 📦 Local Installation & Setup

Ensure you have Python installed locally, then pull down dependencies via the terminal:

```bash
pip install streamlit pandas
```

Launch the secure local server module from your root workspace file path:

```bash
streamlit run "Sustainable Energy Manager.py"
```
